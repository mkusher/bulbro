# Wearables

Some items change how the bulbro looks while it plays: an owned hat is drawn on its head. The look is defined in [ItemAppearance.ts](../src/items/ItemAppearance.ts), separately from the item stats in [Items.ts](../src/items/Items.ts). See [Items](items.md) for the stats.

## How it works

- Each wearable item has an entry in `itemAppearances`. An entry gives the **slot** the item fills, the **atlas** its artwork comes from, and how the artwork is placed.
- Each slot shows at most one item. When several owned items share a slot, the **most recently bought** one is shown. Only the `head` slot exists so far.
- Characters can wear accessories by default (`style.wearingItems`, for example King's crown, defined in `characterWearableAppearances`). An owned item in the same slot replaces the accessory.
- [WearableSprite](../src/bulbro/sprites/WearableSprite.ts) draws the artwork inside the bulbro's scaled container, above the face. It swings, flips and gets the black outline together with the body. Its texture is created once per appearance and shared by every animation frame.
- [BulbaSprite](../src/bulbro/sprites/BulbaSprite.ts) rebuilds its cached animation frames when the visible items change, which only happens after a shop purchase. It keeps the previous frame on screen until the new one is ready.
- The overhead health bar is raised by `appearanceHeadroom`, so tall hats don't cover it. Rotation and `stretchX` are taken into account.

## Appearance fields

Coordinates are in body texture pixels; the body is 100 × 130.

| Field | Meaning |
| --- | --- |
| `slot` | Where the item sits. Only `head` for now. |
| `atlas` | `items` uses the shop icon from `items.png`; `wearables` uses on-character artwork from `wearables.png`; `bulbroHeroes` holds character accessories next to the body parts. |
| `frame` | Atlas frame name; defaults to the item ID. |
| `offset` | Where the frame's center goes, relative to the top-center of the body. |
| `scale` | Overall scale of the 128 × 128 frame. |
| `stretchX` | Extra horizontal scale on top of `scale`, to fit the item around the head. |
| `mirror` | Flips the artwork horizontally. |
| `rotation` | Rotation in radians. |

For reference, the `normal` face is about 64 × 58 at body offset (25, 40), so its center is about (7, 69) relative to the top-center of the body.

## Wearable artwork

`wearables.png` and `wearables.json` are generated by [pack-wearables.ts](../scripts/pack-wearables.ts) from the 256 × 256 shop icons in `src/assets/items`. Each entry removes the parts a worn item would hide:

- `cut`: polygons erased from the icon, in source pixels.
- `clear`: dark regions erased by a flood fill from a seed, up to a luminance limit and bounded by a polygon so it doesn't leak along the outlines.
- `backfill`: makes translucent pixels opaque by blending them over a color (used for a smudge on the helmet icon).

The result is scaled to 128 × 128 cells. Regenerate it from `web/` with:

```sh
bun scripts/pack-wearables.ts
```

To switch an item from its shop icon to wearable art: add an entry to the script, run it, then set `atlas: "wearables"` in `itemAppearances` and adjust `offset` and `scale`. A test fails if an appearance points at a frame that doesn't exist.

### Warrior helmet artwork

The dedicated `src/assets/wearables/warriorHelmet.png` source turns slightly toward the Bulbro’s gaze with a red crest and a transparent open face area. It frames the face like Wolf Helmet. The packer prefers `src/assets/wearables/<id>.png` when present and falls back to the shop icon. The shop artwork is independent.

The artwork was edited using built-in imagegen with this prompt:

> Use case: precise-object-edit. Edit target: the attached silver warrior helmet wearable sprite with red crest. Make only a subtle perspective change: turn the helmet about 12 degrees toward the viewer's RIGHT around its vertical axis, as though its wearer is glancing slightly right. This is a small yaw, not a sideways tilt: keep the helmet upright and keep the overall proportions and height nearly identical. The near left cheek guard and left shell side should be slightly broader; the far right side slightly narrower; face opening center very slightly to the right. Preserve the large unobstructed genuinely transparent face opening, wide enough for the character's two eyes and mouth. Preserve its silver shell, centered-on-the-helmet red crest, cheek guards, thick near-black outlines, crisp cartoon cel shading and restrained highlights. Single centered helmet, fully visible square canvas, same framing and small transparent margins as reference. Genuine transparent outer background AND face aperture. No nose bar, visor, lower faceplate, wearer, face, text, shadows, other objects, or wolf features. Preserve the bold silhouette readable at 48 pixels; avoid a strong three-quarter or profile view.

## Previewing

The **Bulbros / Wearables** Storybook stories render every character with every wearable in a single canvas: **All Bulbros** for the full grid and **One Bulbro** for a single character at a larger scale. Run `bun run storybook` in `web/`.
